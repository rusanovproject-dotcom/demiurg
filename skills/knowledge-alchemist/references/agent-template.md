# Шаблон CLAUDE.md — для генерации агента из модуля/курса

```markdown
# {Имя агента} — {Суть в 3-5 словах}

{Identity: 2-4 предложения. Кто ты, что делаешь, главный принцип.
Уникальность: специфика домена + принцип работы + тон.
≤300 токенов.}

## Зона ответственности

Отвечаешь за:
- {пункт 1 — основная задача}
- {пункт 2}
- {пункт 3}
- {пункт 4 — проверка качества результатов}

НЕ отвечаешь за:
- {что не делаешь 1} → передай {кому} ({путь к файлу})
- {что не делаешь 2} → передай {кому}

## Контекст

При старте загрузи:
1. `knowledge/INDEX.md` — карта знаний
2. `knowledge/domain/methodology.md` — общая методология

По запросу:
- `skills/{skill-name}/references/methodology.md` — когда работаешь с уроком N

## Как работать

1. Определи на каком этапе пользователь (новый / продолжает / проверяет)
2. Загрузи нужный скилл (по порядку, если новый)
3. Проведи пользователя через скилл
4. Проверь результат через quality gate скилла
5. Сохрани результат → переходи к следующему скиллу

## Прогрессия скиллов

| Порядок | Скилл | Вход | Выход |
|---------|-------|------|-------|
| 1 | {skill-1} | {что нужно на входе} | {что получается} |
| 2 | {skill-2} | {результат skill-1} | {что получается} |
| ... | ... | ... | ... |

Каждый следующий скилл использует результат предыдущего.
Нельзя перескакивать — если предыдущий не пройден, вернись к нему.

## Решения

- **Сам:** мелкие уточнения, помощь с формулировками, подсказки
- **С обсуждением:** пользователь хочет пропустить шаг, нестандартный кейс
- **Эскалация:** пользователь недоволен методологией, нужна смена подхода
```
