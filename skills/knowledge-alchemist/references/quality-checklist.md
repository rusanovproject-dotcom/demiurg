# Quality Checklist — Стандарты Demiurg для Knowledge Alchemist

## Чеклист для SKILL.md

- [ ] Description: ≥50 слов, pushy, с синонимами и MANDATORY TRIGGERS
- [ ] Body: ≤500 строк
- [ ] Фазы с quality gates (условие перехода между шагами)
- [ ] Минимум 2 примера Input → Output (включая edge case)
- [ ] Exit criteria: конкретное условие завершения
- [ ] Error recovery: что делать если шаг провалился
- [ ] Heavy content → references/ (Progressive Disclosure)
- [ ] Позитивные формулировки ("делай X" а не "не делай Y")
- [ ] Нет AI-слопа: "leverage", "streamline", "empower", "unleash"

## Чеклист для CLAUDE.md (режим MODULE)

- [ ] Identity ≤ 300 токенов, уникальный
- [ ] Есть принцип работы (не общие слова)
- [ ] "Отвечает за" — 3-5 пунктов
- [ ] "НЕ отвечает за" — 2-3 пункта с КОМУ передать
- [ ] Контекст: ≤5 обязательных файлов
- [ ] Handle-паттерн: ссылки, не inline контент
- [ ] 60-150 строк
- [ ] Решения: 3 уровня (сам / обсуждение / эскалация)

## Чеклист для knowledge/

- [ ] INDEX.md с "Когда загружать"
- [ ] Один факт = одно место (нет дублей)
- [ ] Файлы ≤ 300 строк
- [ ] Нет процессов (процессы → skills/)
- [ ] evolving/ — есть место для самообучения

## Чеклист для references/

- [ ] methodology.md — теория, фреймворки, определения
- [ ] examples.md — good/bad примеры из исходника
- [ ] source-extract.md — полный экстракт (Стадия 2), ничего не потеряно

## Scoring (0-10)

| Балл | Описание |
|------|----------|
| 9-10 | Все чеклисты пройдены, dry-run 2/2, полнота 100% |
| 7-8 | Мелкие пропуски, полнота ≥90%, dry-run pass |
| 5-6 | Существенные пропуски, полнота 70-89% |
| 3-4 | Много пропусков, структура есть но контент слабый |
| 0-2 | Не соответствует стандартам, пересобрать |
