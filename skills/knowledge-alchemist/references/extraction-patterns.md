# Паттерны извлечения для разных типов контента

## Транскрипция видео-урока (самый частый случай)

### Особенности
- Разговорный стиль: "короче", "типа", "блин" — убирай шум, сохраняй суть
- Повторы: автор объясняет одно 2-3 раза разными словами — выбери лучшую формулировку
- "Обучение в процессе": автор показывает на экране — описание действий может быть неполным
- Эмоциональные маркеры: "это самое важное", "запомните" — помечай как приоритет
- Отступления: байки, истории из жизни — сохраняй если в них инсайт

### Маркеры ценного контента
- "Смотрите, как это работает..." → следует техника или фреймворк
- "Ошибка которую все делают..." → антипаттерн
- "Например..." → пример (часто самая ценная часть)
- "Ваша задача..." → задание
- "Разница между X и Y..." → определение или принцип
- "Я глубоко убеждён что..." → принцип автора

### Чистка транскрипции
```
СЫРОЕ: "Короче, блин, вот смотрите, типа, мы берём и делаем вот такую штуку,
        да, то есть, грубо говоря, задаём 5 вопросов"
ЧИСТОЕ: "Задаём 5 вопросов по модели 5W"
```
Сохраняй терминологию автора (если он говорит "хотелки" вместо "потребности" —
сохрани оба варианта, поясни связь).

## Текст книги / статьи

### Особенности
- Структура уже есть (главы, подзаголовки) — используй её
- Меньше шума, больше плотности — каждый абзац может содержать ценность
- Цитаты и ссылки на источники — сохраняй attribution
- Абстракции — нужно конкретизировать для скилла

### Фокус извлечения
- Определения → в ТЕОРИЮ
- Пошаговые инструкции → в ПРАКТИКУ
- Case studies → в ПРИМЕРЫ
- "Распространённые ошибки" → в АНТИПАТТЕРНЫ

## Набор заметок / bullet points

### Особенности
- Часто неполные — нужно достраивать контекст
- Могут быть противоречия — выбери актуальную версию
- Без примеров — нужно генерировать самому (и пометить как сгенерированные)

## Микс (несколько уроков одного модуля)

### Особенности
- Каждый урок → отдельная стадия Extract
- Потом Structure объединяет: общая терминология, единая методология
- Важно: не терять связи между уроками ("после урока 1 вы должны иметь X для урока 2")
- Прогрессия: каждый следующий урок строится на результатах предыдущего

### Паттерн сборки
```
Урок 1: Extract → atoms_1
Урок 2: Extract → atoms_2
Урок 3: Extract → atoms_3
...
Merge: atoms_1 + atoms_2 + atoms_3 → единая Structure
Deduplicate: удали повторы (автор часто напоминает о прошлом)
Link: установи зависимости (урок 2 требует результат урока 1)
```
