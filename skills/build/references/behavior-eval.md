# Behavior Eval — поведенческий тест собранного агента (фаза VALIDATE)

Принцип: **оцениваем результат, а не структуру** («Test how the model uses your tools»).
Статический score — про файлы; eval — про поведение. Без eval «готов» не бывает.

## Тест 1 — Smoke-миссия (обязателен всегда)

Одна реальная задача роли через Agent tool (из чистой сессии, если обёртка создана
в текущей — свежий тип в ней ещё не виден).

- **PASS:** поднялся субагент (маркер «подключился — [Имя]»), ответ матчится на одну
  из форм output contract, родителю хватает ответа без чтения транскрипта.
- **FAIL:** ответ мимо контракта → NEEDS WORK (Refiner); падение / отказ без причины /
  свободное эссе → назад в BUILD. (Синхронно с VALIDATE-секцией SKILL.md.)

## Тест 2 — Discovery-тест триггеринга (5/3)

Проверяет description обёртки как триггер делегирования — отдельно от качества работы.

1. Из TRIGGERS description сгенерируй **5 «своих» фраз** (перефразируй, не копируй дословно).
2. Из ANTI-TRIGGERS и соседних зон — **3 «чужие» фразы**.
3. В ЧИСТОЙ сессии (как и все тесты eval) предъяви все 8 по очереди: «реши, кому делегировать».

- **PASS:** ≥4/5 своих ушли агенту И 3/3 чужих ушли НЕ ему.
- **FAIL → правка description** (директивность, keyword matching, ANTI-TRIGGERS с обеих
  сторон границы), не правка тела агента.

## Тест 3 — Golden-set памяти + recall-probe

Проверяет, что контуры памяти живут, а не задекларированы.

1. **Golden-set:** в smoke-миссию (или отдельную) вшей заведомый урок — факт, которого
   нет в knowledge (например, ограничение клиента). После завершения проверь НА ДИСКЕ:
   - контур 1: `.claude/agent-memory/<name>/` содержит факт;
   - контур 2 (если хук стоит): запись в `ops/agent-captures.jsonl`.
2. **Recall-probe:** НОВАЯ чистая сессия → вопрос, ответ на который есть только
   в памяти агента («что помнишь про X? только из памяти»).

- **PASS:** факт на диске без ручного вмешательства И recall вернул его в новой сессии.
- **FAIL → правка контуров:** нет записи → проверь `memory:` в обёртке; запись есть,
  recall нет → факт не попал в MEMORY.md-индекс (первые 200 строк) — правь курирование.

## Гейт

| Результат | Действие |
|-----------|----------|
| 3/3 PASS | → WIRE |
| Smoke FAIL | мимо контракта → Refiner; падение/эссе → BUILD |
| Discovery FAIL | правка description → повтор теста 2 |
| Recall FAIL | правка памяти → повтор теста 3 |
| 2 круга без PASS | СТОП, эскалация Хозяину |
