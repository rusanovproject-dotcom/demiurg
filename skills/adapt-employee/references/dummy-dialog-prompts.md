# Дамми-диалог — single-subagent two-roles

Демиург запускает **одного** subagent'а с указанием играть **обе роли по очереди** — клиент и агент. Параллельные subagent'ы в Claude Code не вкладываются, поэтому single-mode с переключением по тегам `[КЛИЕНТ]:` и `[АГЕНТ]:`.

Сценарии **не зашиты**, Демиург подбирает на ходу под контекст агента.

---

## Промпт для single-subagent

```
Ты ведёшь дамми-диалог для проверки агента <имя агента> при адаптации в клиентский офис.

Играешь обе роли по очереди, переключаясь по тегам:
- [КЛИЕНТ]: реплика клиента
- [АГЕНТ]: реплика агента

ПРАВИЛА для роли «Клиент»:
Ты играешь клиента <имя из client-profile.md ИЛИ generic 35-летнего онлайн-эксперта>.

Твой профиль: <релевантные поля из client-profile.md — ниша, боль, опыт>

Ты НЕ знаешь:
- Имена файлов агентов
- Slash-команды
- Методологии (БПСВ, Value Equation и т.д.)
- AI-кухню (промпты, токены, контекст)

Ты задаёшь вопросы как нормальный человек, который пришёл за помощью к специалисту. Никакого жаргона. Если агент использует тех-термин который ты не знаешь — переспроси «это ты о чём?» или «не понял».

Сейчас — первое знакомство с агентом <имя агента>. Открыл клиентский офис, видишь приветствие.

Сценарий: <Демиург подбирает по контексту>
- (а) Только приветствие — реагируй живо, естественно
- (б) Спроси что-то по специализации агента (вытяни описание роли)
- (в) Задай сложный вопрос / тяни в чужую зону / путай терминологию

Каждая реплика клиента — 1-2 предложения, живо.

ПРАВИЛА для роли «Агент»:
Ты — <имя агента>, работаешь СТРОГО по этим инструкциям (играй точно как они написаны, включая все служебные строки если они там предписаны):

<полный core.md агента>
<полный soul.md агента>
<релевантные SKILL.md скиллов>
<overrides.md если есть>

Клиент в твоём офисе. Это первая встреча. Отвечай как живой партнёр согласно своей инструкции. Все правила соблюдай дословно — даже если они кажутся служебными. Это тест, нам нужно увидеть как агент реально работает.

ФОРМАТ ВЫВОДА:
Веди диалог 3-5 ходов. После последнего хода — стоп. Никаких метакомментариев.

Пример формата:
[КЛИЕНТ]: Привет, расскажи кто ты.
[АГЕНТ]: <твоя реплика>
[КЛИЕНТ]: <реакция>
[АГЕНТ]: <реплика>
...
```

---

## Сценарии (примеры — не зашиты, для вдохновения)

### Сценарий A — Чистое приветствие
1. Клиент: «Привет, расскажи кто ты и как мы будем работать»
2. Агент: <реплика>
3. Клиент: «Окей, с чего начнём?»

**Что ловим:** утечка имён файлов / slash-команд / методологических терминов в первых 3 репликах.

### Сценарий B — Стресс-тест на жаргон
1. Клиент: «У меня просел отдел продаж, помоги»
2. Агент: <реплика>
3. Клиент: «А что значит [тех-термин который агент использовал]?» (если использовал)
4. Агент: <реплика>

**Что ловим:** способен ли объяснить термин на пальцах, не уходит ли в методологию.

### Сценарий C — Чужая зона
1. Клиент: «Слушай, мне нужен лендинг прямо сейчас, сделаешь?»
2. Агент: <реплика — должен передать дизайнеру / Director'у БЕЗ упоминания slash-команд и имён файлов>

**Что ловим:** говорит ли «передам [имя агента]» по-человечески или «запускаю /designer-build».

### Сценарий D — Путаница терминов
1. Клиент: «Хочу сделать аватар для рекламы» (имеется в виду креатив, не методологический «avatar = ICP»)
2. Агент: <реплика — должен **уточнить** что клиент имеет в виду, не вывалить методологию>

**Что ловим:** не садится ли в позу методолога.

## Что оценивает Демиург по транскрипту

После завершения дамми-диалога Демиург смотрит лог и оценивает:

| Критерий | Pass / Warn / Fail |
|----------|-------------------|
| Тон живой, не служебный | ✓ / ⚠ / ✗ |
| Нет имён файлов в речи | ✓ / ✗ |
| Нет slash-команд в речи | ✓ / ✗ |
| Нет тегов `[XXX]` в речи | ✓ / ✗ |
| Методологические термины объяснены или избегаются | ✓ / ⚠ / ✗ |
| Чистое первое приветствие | ✓ / ⚠ / ✗ |
| Передача в чужую зону без жаргона | ✓ / ⚠ / ✗ |
| Адекватная реакция на путаницу | ✓ / ⚠ / ✗ |

Каждый ⚠ или ✗ → finding с severity (BLOCKER если в первых 3 репликах, MEDIUM дальше).

---

## Минимум для запуска

Если у клиента нет `client-profile.md` — Демиург **подставляет generic-профиль**:
- Возраст 35
- Ниша: «онлайн-эксперт» (общая)
- Опыт: 5 лет в своей теме, новичок в маркетинге/AI
- Боль: «не знаю как масштабироваться»

Это запасной вариант, не основной — Хозяину рекомендуется заполнить client-profile.md перед адаптацией.
