# Improvements — топ идей для будущих презентаций агентов

После кейса Логоса я вижу 7 направлений как сделать презентацию ещё полезнее и интерактивнее. Это не «фантазии о фичах» — каждое решает конкретную проблему которую я заметил в нашем процессе.

Каждая идея — отдельная фаза. Не натягивать все сразу — выбирать 1-2 на следующую презу, тестировать, оставлять что работает.

---

## 1. Speaker Notes — закадровый текст для вебинара (приоритет P0)

**Проблема:** Хозяин ведёт вебинар по презе. На каждом слайде ему нужны опорные точки — что сказать вслух, какую историю рассказать. В кейсе Логоса этого не было — Хозяин либо импровизирует, либо открывает copy-v3.md рядом и читает оттуда.

**Решение:** в каждом слайде snippet `<aside class="speaker-notes" hidden>` с 30-60 секундным текстом. Toggle через клавишу `S` или кнопку в углу. Видна только ведущему (можно через ?presenter=1 в URL).

**Что внутри:**
- Якорь: «Здесь пауза 5 секунд, дай ученику почувствовать»
- История: одна короткая личная байка под слайд
- Связка: «дальше говорю про 5 надстилей — переход через "поверх голоса..."»
- Что НЕ говорить: «не лезь в "что такое камертон" — это термин»

**Тех. реализация:** vanilla JS — `addEventListener('keydown', (e) => e.key === 's' && toggleNotes())`. CSS классы `.presenter-mode .speaker-notes`.

## 2. Embed мини-чата с реальным агентом (приоритет P0)

**Проблема:** ученик видит «Логос пишет тексты как ты», но НЕ пробует сам. Конверсия в первое действие низкая. Между «увидел» и «запустил /voice-dna в своём офисе» — пропасть.

**Решение:** на слайде 7 (или отдельном предпоследнем) — встроенный чат с агентом через iframe. Можно:
- Embed Claude.ai через публичный share-link (если Anthropic откроет)
- Свой эндпоинт: simple wrapper `/api/agent-chat` который проксирует в Claude API с предустановленным system-prompt из `core.md` агента
- Готовое решение: `chatbase.co`, `fastbots.ai` — embed widget

**Минимальный вариант:** одно текстовое поле + кнопка «Спросить Логоса». Ученик вводит вопрос → видит как агент отвечает в реальном голосе. Это конвертит лучше любого описания.

**Где разместить:** между слайдами 6 (знакомство) и 7 (скиллы). Логически — «вы уже пообщались, теперь расскажу как я устроен».

## 3. A/B демо «угадай — это AI или это голос автора?» (приоритет P1)

**Проблема:** на слайде 4 («почему обычный AI пишет плохо») мы УТВЕРЖДАЕМ что ученик чувствует разницу. Но не показываем что он сам её различает.

**Решение:** мини-квиз из 3-4 пар. Каждая пара — два текста на одну тему. Один написан обычным AI без голоса, второй — агентом с voice.md. Ученик кликает «А или Б». Получает результат («3 из 4 правильно — голос работает шкурой») + кнопку дальше.

**Где разместить:** между слайдами 4 и 5 (между «причиной» и «поворотом»). Усиливает нарратив через личный опыт.

**Тех. реализация:** localStorage сохраняет ответы, простой JS counter. 4 пары текстов готовятся один раз для конкретного агента.

## 4. Кликабельная навигация к файлам в Github-репо (приоритет P1)

**Проблема:** на слайде 9 (карта папок) hover-описания и модалки рассказывают про файлы агента. Но ученик не знает что эти файлы РЕАЛЬНЫЕ — лежат в его офисе/в публичном репо. Это снижает доверие («может это маркетинг?»).

**Решение:** в hover-панели добавить кнопку `[GitHub →]` которая ведёт на конкретный файл в публичном репо агента. Ученик кликает на `voice.md` в карте → видит панель с описанием → жмёт GitHub → открывается реальный файл.

**Что нужно:**
- У агента должен быть публичный репо (например, `alex-marketer-pack` для Алекса)
- В fileMap кроме `short` и `full` — поле `github_url`
- Кнопка в модалке/панели

**Преимущество:** ученик видит что агент реальный, не презентационный. Можно сразу склонировать.

## 5. Roadmap агента с прогресс-барами (приоритет P1)

**Проблема:** на слайде 14 (сейчас «список скиллов») мы перечисляем команды списком. Но не показываем что есть СЕЙЧАС vs что в АПДЕЙТЕ. У ученика нет ощущения что агент растёт.

**Решение:** заменить статичный список на двухколоночный roadmap:

```
СЕЙЧАС РАБОТАЕТ          ⏳ В АПДЕЙТЕ
[████████████] /voice-dna     [██░░░░░░] /smart-rewrite
[████████████] /stop-slop     [█░░░░░░░] /angle-shift
[████████████] /style-switch  [░░░░░░░░] /save-to-hub
```

Прогресс-бар показывает % готовности. Под roadmap — одна строка: «Апдейты приходят в твой офис автоматически — не надо покупать отдельно.»

**Тех. реализация:** простой CSS — div с background-gradient. Данные из `<agent>/roadmap.md` (новый файл агента).

## 6. Voice-over export для тех кто не читает (приоритет P2)

**Проблема:** часть учеников не любит читать слайды. Хотят слушать.

**Решение:** в каждом слайде — кнопка `[▶ Listen]` которая воспроизводит mp3 с озвучкой основного текста этого слайда. Озвучка через ElevenLabs или OpenAI TTS, голос — клон Хозяина (если есть voice ID). Файлы лежат рядом с index.html, формат `slide-N.mp3`.

**Минимальный вариант:** один трек на всю презу (5-7 минут lecture-style audio), плеер фиксированный снизу. «Не хочешь читать — слушай.»

**Преимущество:** для дальнобойного аудиовоспроизведения вебинара можно прикладывать к записи как чистый аудио-вариант.

## 7. Карта эволюции агента (changelog визуально) (приоритет P2)

**Проблема:** агент меняется. Версия от 2026-04-15 отличается от 2026-05-05. Ученик который зашёл сегодня НЕ знает что было раньше — но это часть истории агента, его рост.

**Решение:** последний слайд (16.5 или после CTA) — горизонтальная timeline:

```
┌─ 2026-03-20 ─┐  ┌─ 2026-04-15 ─┐  ┌─ 2026-05-05 ─┐
│ Логос v0.1    │  │ Логос v0.5    │  │ Логос v1.0    │
│ Базовый       │  │ + voice-dna   │  │ + 5 надстилей │
│ копирайтинг   │  │ + stop-slop   │  │ + style-switch│
│              │  │              │  │ + динам. память│
└──────────────┘  └──────────────┘  └──────────────┘
                                              ▲
                                              ты здесь
```

Каждая точка кликабельна → модалка с changelog того периода.

**Тех. реализация:** данные из `<agent>/changelog.md`. Парсится в JS, рендерится timeline.

**Преимущество:** показывает что агент = живая система, не статичный продукт. Ученик чувствует что покупает не «коробку», а развивающегося партнёра.

## Бонус: ещё 3 идеи которые могут зайти

### 8. Side-by-side editor для слайда 8.6 (BEFORE/AFTER)

Сейчас BEFORE/AFTER статичные. А что если ученик может ВВЕСТИ свою фразу-команду коррекции в speech-bubble и увидеть как AFTER пересчитается? Через тот же chat-API. Превращает демо в эксперимент.

### 9. Лидерборд «топ-правил overrides от учеников»

Ученики делятся правилами которые добавили в свои overrides.md. Через форму `/submit` отправляется анонимно, попадает в общий пул. На слайде 11 — карусель «Что добавляют другие: "запомни — никогда не используй слово трансформация" / "запомни — каждый пост заканчиваю вопросом" / ...». Подсказывает что добавлять.

### 10. Темнота-светлота как тоггл для AI-слоп слайдов

Toggle `[corporate / brand]` в углу — позволяет увидеть КАК БЫ выглядел тот же контент в стиле агента vs в стиле AI-слопа. Для слайдов 6-16 — переключает на «корпоративный» вид (Inter, светлый фон, bullet-points). Усиливает нарратив контраста — ученик ВИДИТ разницу языков.

## Приоритизация для следующей презы

Если делать одну презу нового агента — выбирай 2 из этих 7:

**Минимум-усилие, максимум-отдача:**
- #1 Speaker Notes (1 час работы, огромное удобство для ведущего)
- #4 Github links в карте папок (30 минут, повышает доверие)

**Если есть время:**
- #2 Embed чата (2-3 часа, конвертит в первое действие)
- #5 Roadmap с прогресс-барами (1 час, показывает рост агента)

**Когда есть бюджет на внешние сервисы:**
- #6 Voice-over export (нужен ElevenLabs / OpenAI TTS API)
- #3 A/B квиз (нужно подготовить пары текстов — час Copywriter работы)

**Долгоиграющая инвестиция:**
- #7 Карта эволюции (нужно вести changelog.md по агенту, окупится через 3-5 апдейтов)

Не пытайся сделать ВСЕ улучшения в одной презе — преза станет перегруженной. Выбирай 2 в каждый раз, тестируй на реальном вебинаре, оставляй что зашло.
