# Scout-досье — здесь НЕ лежат (редирект)

**Канонический путь досье: `knowledge/scout/` в КОРНЕ офиса** (директория с корневым
CLAUDE.md), формат `<slug>-YYYY-MM-DD.md`. Туда пишет скилл `/scout` (`skills/scout/SKILL.md`),
там же их ищет гейт «есть ли досье ≤30 дней» фазы SCOUT.

Эта папка внутри Демиурга — не хранилище (ревью 2026-07-21: расхождение путей делало
фазу ADOPT слепой). Новые досье сюда НЕ класть.

Одобренные находки тиров S/A устанавливаются на фазе ADOPT (таблица «ADOPT-предложение»
в досье → апрув Хозяина → установка → «ADOPT-итог» + `knowledge/{agent}/_toolmap.md`).
